### 1. input
- 월, 시작 요일 입력
  - ex. 5, 월

- 평일 순번 닉네임 입력
- 휴일 순번 닉네임 입력

### 2. output
- 해당 월의 순번 출력
- 평일이면서 공휴일일 경우 휴일 표기
- "n월 m일 요일 [휴일] 닉네임"
- 필요한거
  - 월 정보
  - 평일 리스트 순서
  - 휴일 리스트 순서
  - 공휴일 정보

### 3. domain
- 인력
  - 이름

- 평일 순번
  - 인력 리스트

- 휴일 순번
  - 인력 리스트

- 월
  - enum으로 1월~12월

- 요일
  - enum으로 월~일

- 공휴일
  - enum으로 1.1 3.1 5.5 6.6 8.15 10.3 10.9 12.25

월, 시작 요일 입력받으면 enum에서 꺼내서 출력?

- 근무 배정
  - 월 정보 받아오기
  - 평일 순번, 휴일 순번 받아오기
  - 1일부터 쭉 돌면서
    - 평일이면 평일 순번에서 하나씩 평일 리스트에 추가
    - 휴일이면 휴일 순번에서 하나씩 휴일 리스트에 추가
    - 평일 다음 휴일일 때 같은 사람이면 휴일 순번 다음이랑 변경해서 추가
    - 휴일 다음 평일일 때 같은 사람이면 평일 순번 다음이랑 변경해서 추가
